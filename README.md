# 이미지 생성 프론트엔드 서버

Wan2GP 백엔드와 연동하여 동작하는 한국어 웹 UI 프론트엔드 프로젝트입니다.

## 🚀 주요 기능

- **텍스트에서 이미지 생성 (T2I)**: 프롬프트를 입력하여 고품질 이미지를 생성합니다.
- **이미지 인페인팅 (Inpaint)**: 브러시 도구를 사용하여 이미지의 특정 영역을 마스킹하고 자연스럽게 수정합니다.
- **업로드 이미지 자동 보관 (`inputs/`)**: 사용자가 업로드한 원본 이미지를 `inputs` 폴더에 타임스탬프 기반으로 안전하게 영구 저장합니다.
- **체계적인 제작 로그 기록 (`log/`)**: 이미지 생성 시 실행 시간, 프롬프트, 업로드/생성 이미지 경로, 소요 시간 및 평가 결과를 `log/generation.log`에 자동 기록합니다.
- **시스템 이벤트 & 에러 로그 (`log/sys/`)**: 서비스 시작/종료 시간 및 서버 에러 발생 시각, 상세 Traceback을 `log/sys/event.log`에 철저히 기록합니다.
- **생성 이미지 평가 피드백 UI**: 이미지 생성 완료 및 상세 보기 창에서 👍(좋아요) / 👎(별로예요) 버튼을 통해 품질을 평가하고 제작 로그에 실시간 동기화합니다.
- **생성 결과 갤러리**: 생성된 이미지 목록을 실시간으로 확인하고 다운로드할 수 있습니다.
- **안정적인 아키텍처**: ThreadingHTTPServer와 멀티스레드 FIFO 대기열 시스템을 통해 다중 사용자 요청을 안정적으로 처리합니다.
- **독립된 워커 프로세스**: Gradio API 통신과 GPU 추론을 독립적인 서브프로세스(`generation_worker.py`)에서 실행하여 메인 서버의 블로킹을 방지합니다.

## ⚙️ 요구 사항

- Python 3.8 이상
- 로컬 또는 원격에 기동되어 있는 Wan2GP 백엔드 서버 (기본 포트: 42003)

## 📦 설치 방법

1. 프로젝트 폴더로 이동합니다.
2. 필요한 파이썬 패키지를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```

## 🛠️ 설정 (config.json)

서버 기동 전 또는 운영 중에 `config.json` 파일을 수정하여 각종 설정을 변경할 수 있습니다.

- `wan2gp_url`: 연결할 Wan2GP 백엔드 주소 (기본: `http://127.0.0.1:42003`)
- `server_port`: 프론트엔드 서버를 구동할 포트 (기본: `8080`)
- `outputs_path`: 생성된 이미지가 저장되는 경로
- `inputs_path`: 업로드된 원본 이미지가 저장되는 경로 (기본: `inputs`)
- `log_path`: 제작 로그 및 시스템 로그가 저장되는 경로 (기본: `log`)
- `Enhance Prompt via LLM`: 프롬프트 LLM 향상 기능 설정 (`Based on both Text Prompt and Images Prompts Content` 등)
- `NAG_scale`, `NAG_tau`, `NAG_alpha`: Advanced Generation 관련 제어 파라미터

(참고: `config.json` 설정은 서버를 재시작하지 않아도 이미지 생성 시점에 실시간 반영됩니다.)

## ▶️ 실행 방법

1. 터미널에서 아래 명령어를 통해 프론트엔드 서버를 실행합니다.
   ```bash
   python server.py
   ```
2. 웹 브라우저를 열고 `http://localhost:8080` (또는 설정한 포트)로 접속합니다.
3. 상단의 탭(T2I / Inpaint)을 선택한 뒤, 프롬프트를 입력하고 '새 이미지 생성하기' 버튼을 클릭합니다.
